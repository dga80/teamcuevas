# Team Cuevas Jiu-Jitsu - Landing Page Web

Sitio web oficial de la academia **Team Cuevas Jiu-Jitsu** en Sant Adrià de Besòs (Barcelona).

## 🥋 Características
- **Diseño Responsive:** Optimizado para dispositivos móviles y de escritorio.
- **Estética Dark Athletic:** Basada en tokens visuales y layout de Google Stitch.
- **Sin dependencias externas pesadas:** Desarrollado en HTML5 semántico y CSS moderno puro (Vanilla CSS, sin Tailwind ni frameworks).
- **Contenido Real:** Fotografías, datos e información extraídos del perfil oficial de Instagram `@team_cuevasbjj`.
- **Integraciones:**
  - Enlaces directos a WhatsApp con mensajes preconfigurados para reserva de clase de prueba gratuita.
  - Enlace al perfil de Instagram y galería de la comunidad.
  - Mapa y datos de ubicación en Carrer del Prat, 4.

## 📁 Estructura del Proyecto
```
TCuevas_web/
├── index.html      # Estructura de la landing page
├── styles.css      # Hoja de estilos en Vanilla CSS puro
├── app.js          # Navegación móvil e interactividad
├── images/         # Logo y fotografías del club
└── data/           # Datos extraídos del Instagram oficial
```

## 🚀 Despliegue
Al ser una web estática pura, se puede desplegar instantáneamente en GitHub Pages, Vercel, Netlify o cualquier servidor web simplemente sirviendo la carpeta raíz.
